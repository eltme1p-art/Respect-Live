## ما الجديد في الإصدار 10

### الواجهة
- **الطابع الكلاسيكي (الزجاج السائل)**: الشكل القديم نفسه — أزرق داكن، Tajawal/Orbitron، شريط علوي وسفلي عائمان بعدسة سائلة — مطبّق كطبقة ستايل فقط في `web/css/classic.css`. للرجوع للتصميم الضبابي (Blur) احذف سطر `classic.css` من `web/index.html`.
- **iPhone**: دعم كامل لـ notch وDynamic Island وشريط الصفحة الرئيسية (safe-area) في الوضعين العمودي والأفقي، وبلا زوم تلقائي عند الكتابة (حقول 16px على اللمس).
- **ثبات**: لا تُلمس الصفحة عند التحديث الدوري إن لم تتغيّر بياناتها (لا وميض ولا قفزة تمرير)، والخلفية ثابتة بلا فلاتر متحركة، ولا يتبدّل Service Worker أثناء الاستخدام.
- **كل صفحة مستقلة برابطها**: `/kick` `/youtube` `/x` `/tiktok` `/telegram` `/discord` `/notifications` `/activity` `/live` `/account` `/admin/...` — تفتح مباشرة، تُحدَّث بأمان، وزر الرجوع يعمل.
- **انتقال ناعم بين الصفحات** (View Transitions) يعرف الاتجاه، ويتحول لانتقال خفيف في الوضع الخفيف، ويُلغى لمن يفضّل تقليل الحركة.
- يعمل على كل الأحجام: شريط سفلي للجوال، شريط أيقونات للتابلت، قائمة جانبية للديسكتوب.
- **وضع فاتح / داكن / تلقائي**، ووضع خفيف يُقترح تلقائياً للأجهزة الضعيفة.

### ميزات جديدة
- **سجل الإرسال**: كل رسالة وصلت لقنواتك أو فشلت، مع فلترة حسب المصدر.
- **إرسال تجريبي**: جرّب شكل تنبيه أي قناة على حسابك الشخصي في تيليجرام دون إزعاج قنواتك.
- **إجراءات جماعية**: حدّد عدة قنوات وأوقفها أو أسكتها أو احذفها دفعة واحدة.
- **بحث وفلترة وترتيب** في كل قائمة قنوات.
- **لوحة أوامر** (Ctrl+K): بحث في الصفحات وقنواتك والإجراءات.
- **صفحة على الهواء** تتحدث تلقائياً، ودليل «ابدأ من هنا» للمستخدم الجديد.
- **معاينة حيّة لرسالة تيليجرام** عند تخصيص القوالب والإرسال اليدوي، مع تحسين الصياغة بـ Groq.
- **سحب للتحديث** على الجوال، وعمل جزئي بدون اتصال، وشارة عدد التنبيهات على أيقونة التطبيق.
- **تصدير قائمة قنواتك** كملف JSON.
- للإدارة: **صحة النظام** (حالة كل مهمة دورية)، **تنزيل نسخة احتياطية** من قاعدة البيانات، تنظيف الصور غير المستخدمة، رسم الإرسال لآخر 7 أيام، فلترة المستخدمين والسجل الأمني، وشريط إعلان أعلى الموقع.

### الخادم (أُعيد بناؤه بالكامل)
- مقسّم لوحدات واضحة داخل `app/` بدل ملف واحد بـ 3500 سطر.
- مبني على Starlette مباشرة (الأساس الذي يقوم عليه FastAPI) بدون APScheduler — أخف وأسرع.
- **الإعدادات من الذاكرة** بدل فتح اتصال بقاعدة البيانات لكل قراءة.
- **عميل HTTP واحد مشترك** لكل الطلبات الخارجية (اتصالات مُعاد استخدامها).
- مجدول مهام خاص يسجل نجاح/فشل كل مهمة ومدتها.
- ضغط gzip للملفات والـ JSON، وتخزين طويل للملفات بختم الإصدار.

### الأمان
- حد لمحاولات الدخول الخاطئة لكل IP ولكل حساب.
- كوكيز `Secure` تلقائياً على HTTPS، وتمديد الجلسة للمستخدم النشط.
- **Webhook تيليجرام محمي بسر** — يُرفض أي طلب مزيف.
- رفع الصور يتحقق من محتوى الملف نفسه (لا SVG ولا ملفات متنكرة)، وتُقدَّم الصور بعزل كامل.
- رؤوس حماية (CSP، HSTS، nosniff...) لكل الصفحات.

## المتغيرات — نفسها بدون تغيير

| المتغير | الوصف |
|---|---|
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | حساب المالك |
| `SESSION_SECRET` | 64 حرف hex |
| `DB_PATH` | `/app/data/respect.db` على Railway (مع Volume) |
| `TELEGRAM_TOKEN` | توكن البوت |
| `DISCORD_BOT_TOKEN`, `DISCORD_WATCH_CHANNELS`, `DISCORD_ALLOWED_GUILDS` | ديسكورد |
| `SITE_NAME`, `SITE_COLOR` | اسم ولون الموقع |
| `GROQ_API_KEY`, `TWITTER_BEARER_TOKEN` | اختياري (يمكن إضافتها من لوحة الإدارة) |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_EMAIL` | إشعارات المتصفح |
| `PUBLIC_URL` | اختياري — يُكتشف تلقائياً من Railway |

**قاعدة البيانات متوافقة 100%** — نفس الجداول، ولا تُحذف أي بيانات. الإضافات فهارس للأداء فقط.

## التشغيل

```bash
cp .env.example .env
pip install -r requirements.txt
python main.py        # http://localhost:8000
```

على Railway لا يتغير شيء: نفس أمر التشغيل `uvicorn main:app`، ونفس الـ Volume.

## ملاحظة عن ديسكورد
المشروع يستخدم `discord.py-self` بتوكن حساب شخصي. هذا مخالف لشروط ديسكورد وقد يؤدي لإيقاف الحساب — استخدم حساباً ثانوياً.
