# Respect Live — الإصدار 10

مراقبة بث كيك وتيك توك، وفيديوهات يوتيوب، وتغريدات X، ورومات ديسكورد — وكل تنبيه يصل لقنواتك في تيليجرام.

> **النسخة السابقة محفوظة كاملة** في فرع [`claude/backup-original`](../../tree/claude/backup-original).
> للرجوع إليها: انشر ذلك الفرع بدلاً من `main` في Railway، أو اعمل Revert لهذا الدمج.

---

## ما الجديد في الإصدار 10

### الواجهة (الواجهة القديمة الأصلية كما هي + المزايا الجديدة)
- **الواجهة القديمة نفسها** (`web/index.html`، ملف واحد كما كان) — نفس التصميم والصفحات والألوان، دون إعادة تصميم.
- **تنقل فوري كتطبيق حقيقي**: التبديل بين تبويبات الشريط السفلي لا يعيد بناء الصفحة؛ تُحفظ كل صفحة في الذاكرة مع موضع التمرير فتعود في أجزاء من الثانية، والشريط السفلي لا يُعاد رسمه أبداً، وبلا أنميشن شفافية فوق الزجاج. كل صفحة برابطها (`/kick` `/youtube` `/x` `/tiktok` `/telegram` `/discord` `/notifications` `/account` `/news`) وزر الرجوع يعمل، وضغط التبويب لا يملأ سجل المتصفح.
- **استغلال مساحة جهازك**: عند الفتح تظهر آخر بيانات محفوظة فوراً (لقطة في IndexedDB) ثم تُحدَّث بصمت من الشبكة دون إعادة رسم إن لم يتغير شيء؛ Service Worker يخزّن الواجهة والخطوط والصور فيعمل التطبيق حتى بلا اتصال؛ ويُطلب تخزين دائم (`storage.persist`) كي لا يمسح النظام البيانات.
- **استقرار**: تسجيل الدخول بلا إعادة تحميل للصفحة، ولا تحديث تلقائي مفاجئ للتطبيق (يظهر إشعار «تحديث متاح» وأنت تختار)، وبلا زوم تلقائي عند الكتابة على iPhone.
- **iPhone**: دعم notch وDynamic Island وشريط الرئيسية (safe-area) عمودياً وأفقياً، حتى عند الإضافة للشاشة الرئيسية.
- نسخة الواجهة المعاد تصميمها (v10) محفوظة في `web/v10/` للرجوع إليها.

### ميزات جديدة (بنفس ستايل الواجهة القديمة)
- **سجل الإرسال** (من «حسابي»): ما وصل لقنواتك في تيليجرام وما فشل.
- **إرسال تجريبي** لأي قناة إلى حسابك الشخصي في تيليجرام.
- **تحديد جماعي** للقنوات: تفعيل / إيقاف / إسكات / حذف دفعة واحدة.
- **إشعارات**: قراءة وحذف إشعار واحد، و«قرأت الكل» للأخبار.
- **سحب للتحديث** على الجوال.
- للإدارة: **صحة النظام** (وقت التشغيل، حجم القاعدة، حالة المهام)، **تحميل نسخة احتياطية** من قاعدة البيانات، حذف الصور غير المستخدمة.

### الخادم (أُعيد بناؤه بالكامل)
- مقسّم لوحدات واضحة داخل `app/` بدل ملف واحد بـ 3500 سطر.
- مبني على Starlette مباشرة (الأساس الذي يقوم عليه FastAPI) بدون APScheduler — أخف وأسرع.
- **الإعدادات من الذاكرة** بدل فتح اتصال بقاعدة البيانات لكل قراءة.
- **عميل HTTP واحد مشترك** لكل الطلبات الخارجية (اتصالات مُعاد استخدامها).
- مجدول مهام خاص يسجل نجاح/فشل كل مهمة ومدتها.
- ضغط gzip للملفات والـ JSON، وتخزين طويل للملفات بختم الإصدار.

### الأمان
- حد لمحاولات الدخول الخاطئة لكل IP ولكل حساب.
- كوكيز `Secure` تلقائياً على HTTPS، وتمديد الجلسة للمستخدم النشط.
- **Webhook تيليجرام محمي بسر** — يُرفض أي طلب مزيف.
- رفع الصور يتحقق من محتوى الملف نفسه (لا SVG ولا ملفات متنكرة)، وتُقدَّم الصور بعزل كامل.
- رؤوس حماية (CSP، HSTS، nosniff...) لكل الصفحات.

## المتغيرات — نفسها بدون تغيير

| المتغير | الوصف |
|---|---|
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | حساب المالك |
| `SESSION_SECRET` | 64 حرف hex |
| `DB_PATH` | `/app/data/respect.db` على Railway (مع Volume) |
| `TELEGRAM_TOKEN` | توكن البوت |
| `DISCORD_BOT_TOKEN`, `DISCORD_WATCH_CHANNELS`, `DISCORD_ALLOWED_GUILDS` | ديسكورد |
| `SITE_NAME`, `SITE_COLOR` | اسم ولون الموقع |
| `GROQ_API_KEY`, `TWITTER_BEARER_TOKEN` | اختياري (يمكن إضافتها من لوحة الإدارة) |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_EMAIL` | إشعارات المتصفح |
| `PUBLIC_URL` | اختياري — يُكتشف تلقائياً من Railway |

**قاعدة البيانات متوافقة 100%** — نفس الجداول، ولا تُحذف أي بيانات. الإضافات فهارس للأداء فقط.

## التشغيل

```bash
cp .env.example .env
pip install -r requirements.txt
python main.py        # http://localhost:8000
```

على Railway لا يتغير شيء: نفس أمر التشغيل `uvicorn main:app`، ونفس الـ Volume.

```
main.py                 ← نقطة الدخول
app/
  config.py db.py security.py http.py state.py jobs.py main.py
  services/   telegram · sources (كيك/يوتيوب/X/تيك توك) · discord_bridge · images · extras (Push/Groq/الحدود)
  routes/     auth · telegram · channels · content · discord · admin · pages
web/
  index.html  sw.js  icon.svg   ← الواجهة القديمة (ملف واحد) + Service Worker
  v10/                          ← واجهة الإصدار 10 المعاد تصميمها (احتياط، غير مستخدمة)
backup/v9/                      ← ملفات الإصدار السابق كما كانت
```

## ملاحظة عن ديسكورد
المشروع يستخدم `discord.py-self` بتوكن حساب شخصي. هذا مخالف لشروط ديسكورد وقد يؤدي لإيقاف الحساب — استخدم حساباً ثانوياً.
